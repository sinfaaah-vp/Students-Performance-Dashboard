# Student Performance Dashboard – Excel

## Project Overview
An interactive Excel dashboard developed to monitor and analyse student performance and attendance records.

## Objectives
- Monitor student attendance and performance.
- Track student records based on selected names.
- Analyse attendance status and daily records.
- Provide an organised view of student information.
- Make student record management easier.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Cleaning
- Interactive Dashboard

## Key Features
- Interactive student selection.
- Student-wise performance tracking.
- Attendance monitoring.
- Date-wise student records.
- Organised dashboard for easy analysis.

## Project Files
- Excel dashboard file.
- Dashboard screenshots.

## Purpose
This project demonstrates the application of Microsoft Excel in data management, performance monitoring and interactive reporting.
